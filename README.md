Online Boot Camp Website
This project is an online boot camp platform designed for students to register, log in, and access a wealth of educational resources, including books, class videos, and live learning sessions. The application uses JWT for secure authentication and authorization.

Features
User Authentication: Secure login and registration using JWT.

Access to Educational Resources: Students can access books, class videos, and participate in live sessions.

Responsive Design: Ensures a seamless experience across all devices.

Interactive Learning: Includes live sessions for real-time learning and interaction.

Technologies Used
Front-End: React, HTML, CSS, JavaScript

Back-End: Node.js, Express.js

Authentication: JWT (JSON Web Tokens)

Database: MongoDB (or Firebase, based on your preference)

Tools: Git, npm, Webpack, Babel

Installation
Clone the repository:

git clone https://github.com/tekluabayneh/online_bootCamp_platform.git
cd bootcamp-website
Install dependencies:

npm install
Set up Backend:

Configure your JWT secret and database connection in the .env file.

Run the application:

npm start

Usage
Sign Up/In: Users can sign up or log in using their email and password.

Access Resources: Students can access a variety of educational materials, including books and class videos.

Live Sessions: Participate in live sessions for interactive learning.

Profile Management: Users can manage their profiles and track their progress.
